# MarketMate AI roadmap

- [ ] Design system (dark navy + green fintech), app shell with mobile bottom nav
- [ ] Auth (email/password, Google, Lovable) + profiles
- [ ] Database: suppliers, products, price history, policies, orders, events, wallet txs, chat, agent identity
- [ ] Supplier marketplace: register business, list products, prices, inventory, receive/confirm orders, delivery status
- [ ] Spending controls (per-tx, daily, approved suppliers/tokens, approval rules, autonomous rule)
- [ ] Agent wallet on Celo mainnet (server-signed USDC/USDT/USDm transfers, policy-enforced)
- [ ] Orders dashboard with tx hashes + Celoscan links
- [ ] AI procurement chat (one conversation, saved to account) with search/compare/rank/propose tools
- [ ] Market intelligence (price comparisons, trends, FX via Mento onchain + offchain, savings)
- [ ] x402 paid market-data endpoint + agent pays per request
- [ ] ERC-8004 agent identity registration + reputation display
- [ ] Dashboard (balances, totals, savings, active orders, supplier performance, recent txs)
- [ ] Secrets: agent wallet key, x402 facilitator key
- [ ] Tests for spending rules and ranking
